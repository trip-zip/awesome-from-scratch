# 11-dashboard

Checkpoint 11 of *Awesome From Scratch*: **the control center**.

Read the chapter: <https://somewm.org/docs/tutorials/from-scratch/11-dashboard>

## Run this checkpoint

```bash
git checkout 11-dashboard
somewm-client test start --config "$PWD/rc.lua" --name afs
```

That opens a nested SomeWM in a window. Your real session is untouched.
